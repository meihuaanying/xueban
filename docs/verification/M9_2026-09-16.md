## 3. 关键实现与决策

1. **同步策略**：以「版本号比对 + 各端自刷新」为唯一同步语义（轮询 5s），WebSocket 通道仅推送同一版本/摘要，避免多套增量同步逻辑产生不一致；同步失败静默重试，不打断学习。
2. **离线幂等**：`practice_records(user_id, client_event_id)` 唯一约束；重放请求返回原判定结果并标记 `duplicate=true`，客户端可提示「已同步（未重复计数）」。
3. **暗色防闪烁**：官网在 `<head>` 内联脚本、桌面在布局挂载时读取主题；`ThemeToggle` 持久化到 `localStorage.xueban.theme`。
4. **三态可测性**：为 Error/Empty 组件补 `data-testid`，E2E 用路由拦截（500 / 延迟）稳定复现错误态与加载态。
5. **新手动线**：引导不强制诊断（20 题会劝退新用户），提供「跳过诊断，先体验一次讲解」，满足 ≤5 步目标。
