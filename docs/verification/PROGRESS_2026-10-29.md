   `scripts/pregenerate_videos.py --limit 100`（幂等续跑）。
3. **题库队列停在「初中数学」**：状态文件 `next_index=10`，自 09:20 起 PUBLISHED 无增长，
   与 LLM 配额耗尽时间一致。恢复后 `run_content_queue.py --resume` 继续。
4. **云 TTS 未接入**：`TTS_PROVIDER=windows` 仅本机开发通道；生产需 Azure Key，
   启动校验会拒绝 windows/mock。
