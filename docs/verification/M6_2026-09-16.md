## 3. 关键实现与决策

1. **API 复用**：移动端直接对接 M1~M3 后端契约（认证/诊断/规划/讲解/练习/复盘/订阅），与桌面端同源；`EXPO_PUBLIC_API_BASE_URL` 可覆盖基址（真机联调需改为局域网 IP）。
2. **SSE 兼容**：React Native 的 fetch 流式支持不稳定，采用 XMLHttpRequest `onprogress` 增量解析 SSE（start/delta/done），并保留非流式 `hint` 回退，保证弱环境可用。
3. **SecureStore 隔离**：`src/lib/auth.tsx` 仅在原生环境调用 SecureStore，测试环境静默降级（jest mock）。
4. **拍照/语音 mock-first**：上传走真实 MinIO 预签名链路；OCR/ASR 供应商在 M8 接入，界面提供降级提示与结果展示位。
5. **Maestro 流程**：两条 YAML（注册→诊断→计划→打卡 / 练习→错题→重练），使用 RN `testID` 映射的 resource-id 选择器；手机号经 `-e PHONE=` 注入避免账号冲突。
