# 妹妹试用观察清单（2026-10-04）

> **给陪玩的人（爸爸妈妈）看，不是给妹妹看的。**
> 用法：妹妹自己玩，你在旁边**少说话、别教**，只记「她的行为」和「她的话」。
> 一次玩 15~20 分钟就够（应用自己也会在 20 分钟强制休息），**别硬撑到她烦**。

---

## 怎么用这份清单

1. 先按 [`desktop-trial-setup.md`](./desktop-trial-setup.md) 把应用跑起来，确认她看到的是**图标导航 + 熊猫吉祥物**（儿童模式）。
2. 找到一支铅笔（或手机备忘录），一边陪一边记。每条只记**发生了什么**，不写评价。
3. 结束时把「结论」那几行填一下。有 ❌ 的不要紧——**这正是我们要的**，比「都挺好」有用一百倍。

### 最重要的纪律

- **不要在观察时教她怎么用**。她卡住是这次试玩最有价值的数据；你一教，这个数据就没了。
- **不要在她做题时替她点**。
- 她说「不想玩了」就**立刻停**，记下时间点和当时在做什么。
- 中途你想喊停、要查日志、要看接口，**等她这次玩完再弄**。

## 一、四个重点观察项（用户点名，必须答）

### ① 能否**不看字**独立导航

**怎么测**：不提示她，只说「你想做什么就点什么」。看她能不能自己从当前页走到别的页。

- [ ] 她点的是**图标**还是先去找文字？
- [ ] 她知不知道顶上的熊猫是干什么的？（不提示，看她会不会主动点）
- [ ] 她会不会**误触**到不该去的页（比如点进「诊断」「复习」）？
- [ ] 卡住时她的第一反应是什么？（乱点 / 喊人 / 自己退出去）

**记下来**：
```
她是怎么找到「错题」的：
她点错的地方：
她求助的次数：___ 次
```

### ② 三层提示**能不能等住**

这是产品红线：不直接给答案。为什么要看这个——**一个 7 岁孩子往往忍不住点到底层**。

**怎么测**：在「学习单元」页故意**答错一道题**，看她会不会一路把三层提示点完。

- [ ] 答错后她会不会主动点「看讲解」？
- [ ] 点开第一层后，她是**继续想**还是**立刻点下一层**？
- [ ] 她有没有表现出「快点给出答案」的着急？（叹气、说「直接告诉我嘛」）
- [ ] 提示看完她会不会**再试一次**，还是直接放弃？

**记下来**：
```
她一共点到了第几层：___ 层
在第一层停留了多久：___
她说的原话（越原越好）：
```

### ③ 动画讲解她**看不看得完**

**怎么测**：在错题页点「🎬 动画讲解这个知识点」（或知识地图节点），看播放过程。

- [ ] 她愿不愿意点这个入口？（入口不明显她会直接跳过）
- [ ] 打开后她有没有**继续看**，还是很快就退出去？
- [ ] 她有没有**动手操作**页面里的按钮？（比如点选项、拖一拖）
- [ ] 讲解里的**语音**她会不会跟着听？（会不会因为没声音而不知道该干嘛）
- [ ] 讲完后她有没有说「我知道这道题了」之类的**正反馈**？

**记下来**：
```
她看了多久：___
她有没有动手点：___
她有没有主动说「我懂了」：___
（如果降级成图文版）她看了没：___
```

### ④ 20 分钟**强制休息**的反应

这是未成年人保护（§8 约束 2），必须让她提前知道规则，别到时候像被罚站。

**怎么测**：正常玩到 20 分钟，或者中途手动把 `localStorage` 的 `xueban.session.active-ms` 设成 21 分钟（见 setup 文档）。

- [ ] 快到时间时她看到顶部**提醒**了吗？
- [ ] 进入休息画面后，她的第一反应是什么？
- [ ] 她会不会**试图跳过**？（点按钮、乱按、想关窗口）
- [ ] 休息倒计时她**看得懂**吗？（知道还要等多久、还要做什么）
- [ ] 休息结束后她愿意**继续**吗？

**记下来**：
```
她对休息的第一反应：
她说了什么：
休息后是否愿意继续：
```

## 二、其余要顺带看的（不重点，但值得记）

| 看什么 | 关注点 | 记下来 |
|---|---|---|
| **题做对时** | 撒花动效她注意到吗？会不会主动提「再来一题」？ | |
| **朗读按钮** | 她会不会主动点喇叭？点了之后会不会跟着念？ | |
| **识字题（点选）** | 汉字卡够大吗？会不会点错到旁边的字？ | |
| **连线题** | 点左再点的配对她会吗？配错了能不能自己改？ | |
| **中文显示** | 有没有豆腐块、乱码、看不清的字？ | |
| **字号** | 有没有哪处字她嫌小、凑近看？ | |
| **休息之后** | 回来时还记得刚才做到哪吗？ | |
| **她主动关掉了吗** | 玩到一半说「不玩了」，还是玩到我们收？ | |

## 三、术语对照（你可能不知道这些是啥）

| 屏幕上的字 | 实际是什么 | 给孩子的一句话 |
|---|---|---|
| 🔥 今天 | 今天该学什么 | 「今天从这儿开始」 |
| 🩺 诊断 | 摸底测验 | 「看看哪些会哪些不会」 |
| 🗺️ 计划 | 排接下来学什么 | 「接下来咱们学这个」 |
| 📖 单元 | 看讲解 + 做题 | 「在这儿学」 |
| 🧩 错题 | 做错的题 | 「上次这道再做一次」 |
| 🔁 复习 | 把记住的再巩固 | 「回头再看一遍」 |
| 🎬 动画讲解 | AI 做的互动小网页 | 「点这个会动起来」 |
| 🐼 小伴 | 吉祥物 | 「点小熊会说话」 |

## 四、结论（玩完再填）

| 问题 | 你的回答 |
|---|---|
| 她能自己走完「今天 → 学习单元 → 做几道题 → 看讲解」吗？ | 能 / 要人带 / 走不动 |
| 她会主动要点「动画讲解」吗？ | 会 / 不会 / 看情况 |
| 三层提示她等得住吗？ | 等得住 / 忍不住点到底 / 没试出来 |
| 20 分钟休息她接受吗？ | 接受 / 有抱怨 / 试图跳过 |
| 她还想再玩吗？ | 很想 / 一般 / 不想了 |
| **最让你意外的一件事** | |
| **最让你不满意的一件事** | |

## 五、回来之后

把这张清单的「结论」那几行告诉开发者（或者直接把这张纸/截图丢过去）。
**不需要你写代码、不需要你提修复方案**——只要说清楚「她做了什么、说了什么」，问题该怎么改是我们的事。
