## 6. 工程决策与偏差记录（透明留档）

| # | 事项 | 处理 | 影响 |
|---|------|------|------|
| 1 | Docker Hub `minio/*` 仓库已下架（`pull access denied`） | 改用官方 `quay.io/minio/minio` / `quay.io/minio/mc` | 技术栈不变（仍为 MinIO），仅镜像仓库变更 |
| 2 | Langfuse v3 要求 `ENCRYPTION_KEY` 为 64 位 hex | 修正 compose 默认值与 `.env.example` 注释 | worker/web 已正常运行 |
| 3 | nativewind 4.2.x 依赖 reanimated 4 的 `react-native-worklets/plugin`，与 Expo SDK 53（reanimated 3.17）不匹配 | 锁定 `nativewind@4.1.23` | 与 Expo SDK 配套，移动端构建/测试通过 |
| 4 | `react` 19.0.0 与 `react-dom` 19.3.0 版本不一致导致测试报错 | 全仓 `pnpm.overrides` 锁定 react/react-dom 19.0.0 | 与 Expo SDK 53 要求一致 |
| 5 | Next 构建将 tsconfig `jsx` 改为 `preserve`，导致 web 测试 `React is not defined` | web 测试配置显式 `esbuild.jsx = "automatic"`；共享 nextjs preset 同步 `jsx: preserve` | 构建与测试解耦，`--force` 全量重跑复验通过 |
| 6 | `next-env.d.ts`（Next 自动生成）触发 lint 规则 | 加入共享 ESLint 全局忽略 | — |
| 7 | GitHub Actions 只识别 `.github/workflows/` | 工作流置于根目录，`infra/ci/` 放说明占位 | 与 §4 目录结构对应关系已在 README 注明 |
| 8 | `docker compose` 需在含 compose 文件目录执行 | 根目录新增 `docker-compose.yml`（`include` 引用 `infra/docker/`，单一事实来源） | 规格书原文门禁命令可在仓库根原样执行 |
