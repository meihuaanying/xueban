## 4. 关键设计（详见 ADR-002）

1. 向量维度 1024（bge-m3 对齐），题目内联存储 + HNSW 余弦索引。
2. Embedding/Rerank 双供应商抽象：mock（离线/CI）与硅基流动（真实语义），切换只改 `EMBEDDING_PROVIDER` / `RERANK_PROVIDER`。
3. 两段式检索：向量召回（candidate_k≥20）→ 重排 top_k；重排不可用自动回退向量分数。
4. 迁移内置 `CREATE EXTENSION IF NOT EXISTS vector`，全新环境零手工步骤（测试库/CI 已验证）。
5. 分块保留页码区间，为 F-37「回答带页码引用」预留元数据。

## 5. 测量说明

- **词面召回 vs 语义召回**：当前评测 100% 基于 mock 词面向量（演示题库题干含知识点前缀）。真实 bge-m3 语义召回需硅基流动 Key（`SILICONFLOW_API_KEY`），已记录于 `docs/BLOCKERS.md` B-003；接入后执行同一脚本复测即可。
- **导入去重口径**：以 `(subject, stem)` 唯一去重，重复计入 `skipped` 不计 `invalid`（幂等语义）。
