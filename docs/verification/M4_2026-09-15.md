## 4. 本里程碑关键实现与决策

1. **CORS 直连**：后端新增 `cors_allow_origins`（默认 `localhost:3000`）并挂载 `CORSMiddleware`（最外层，优先处理预检），新增 3 个契约用例（预检放行、响应头、未知来源拒绝）。官网浏览器端直接调用 `POST /v1/auth/register` 与 `POST /v1/billing/trial`。
2. **官网 API 访问**：客户端使用 `NEXT_PUBLIC_API_BASE_URL`（默认 `http://localhost:8000`）；定价页 SSR 拉取套餐，API 不可达时回退静态套餐，保证构建与 Lighthouse 不受后端可用性影响。
3. **E2E 跑生产构建**：Playwright webServer 使用 `next start`（而非 `next dev`），既避免 dev 清空 `.next` 影响后续 Lighthouse，又直接验证构建产物；PostgreSQL 需已迁移。
4. **按需转译**：`experimental.optimizePackageImports: ["@xueban/ui"]` 解决 barrel 导出把 recharts/katex 打入首屏的问题（282 kB → 115 kB）。
5. **SEO 完整性**：sitemap/robots/JSON-LD/canonical/openGraph 全量落地；`/app` 私有页 noindex 且不进入 sitemap；帮助页 FAQ 使用原生 `<details>` 保证正文可爬取。
6. **Lighthouse 口径**：默认移动端仿真（Lighthouse 标准口径）、`numberOfRuns: 3` 取中位数；四项断言均为 error 级，并以 FCP≤1ms 的负向对照验证断言机制真实生效。
7. **B-002 闭环**：E2E 自动截图首页、主色按钮、注册页与试用状态，写入 `docs/verification/assets/`；桌面/移动端截图在 M5/M6 E2E 中补充。
