# 1) forms.tsx 到底导出什么

### 误判原因（如实登记）

初稿只对 `forms.tsx` 做了一次 **局部 grep**（命中 `Label` 就下了「只导出 `Label`」的结论），既**没有读全文件**，也**没有核对调用方**（`apps/desktop/src/routes/login.tsx` 一直是 `import { Input } from "@xueban/ui"`）。这是一个「取证不足即下结论」的错误。

### 教训（与本项目历次同源）

这是本项目第 8 次同源问题：**报告/结论里的每个数字与 ✅ 都必须有文件与测试为证；判断「某组件/某能力缺失」时，必须至少做三件事——读全定义文件、查调用方、必要时查 `git log -S` 确认演进史。** 只用一次局部 grep 就写对外文档，会把「我这次没搜到」误当成「它不存在」。
