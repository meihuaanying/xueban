# T-013: 迁移 c4f1a2b7d9e0 与 ORM 的 server_default 不对称，Alembic autogenerate 漂移

## 元数据
- id: T-013
- severity: P2
- confidence: verified
- depends_on: none
- allowed_files:
  - services/api/app/models/learning.py
- allowed_extra_paths: none

## 问题描述
迁移 `c4f1a2b7d9e0_profile_dimensions.py` 为 `learning_profiles` 新增的三列（cognitive_profile/behavioral_profile/affective_profile）均声明 `server_default=sa.text("'{}'::jsonb")`，而 ORM 侧 `LearningProfile` 同三列只有 Python 级 `default=dict`、未声明 `server_default`。DB 实际 schema 与 ORM 声明存在默认值不对称：下次 `alembic revision --autogenerate` 会反复产生"删 server_default"的伪差异，破坏 ADR-001 决策 6「保证 Alembic autogenerate 稳定」。同表旧列 `behavior_stats` 在初始迁移与 ORM 两侧均无 server_default，属一致，不在本任务范围。

## 预期行为
- E-012（docs/adr/001-schema.md §决策 6）：约束/默认值声明保证 Alembic autogenerate 稳定。

## 定位锚点
- 文件: services/api/app/models/learning.py
- 符号: LearningProfile
- 锚点代码: `    cognitive_profile: Mapped[dict[str, Any]] = mapped_column(JSONB, default=dict, nullable=False)`
- 行号参考: 79（behavioral_profile 80 / affective_profile 81）

## 修复指令
在 `services/api/app/models/learning.py` 的 `LearningProfile` 中，将锚点及相邻两行：
`    cognitive_profile: Mapped[dict[str, Any]] = mapped_column(JSONB, default=dict, nullable=False)`
`    behavioral_profile: Mapped[dict[str, Any]] = mapped_column(JSONB, default=dict, nullable=False)`
`    affective_profile: Mapped[dict[str, Any]] = mapped_column(JSONB, default=dict, nullable=False)`
分别替换为带 `server_default=text("'{}'::jsonb")` 的形式，例如第一行替换为：
`    cognitive_profile: Mapped[dict[str, Any]] = mapped_column(JSONB, default=dict, server_default=text("'{}'::jsonb"), nullable=False)`
（另两行同构；`text` 从 `sqlalchemy` 导入——在文件头 `from sqlalchemy import ...` 中追加）。`behavior_stats` 保持不变。不得修改该模型其他列。
