# T-012: purge_deleted_accounts 内 return 之后残留不可达的 session.flush()

## 元数据
- id: T-012
- severity: P2
- confidence: verified
- depends_on: none
- allowed_files:
  - services/api/app/services/auth_service.py
- allowed_extra_paths: none

## 问题描述
`purge_deleted_accounts` 在 `return user_ids`（行 326）之后残留一行 `    await session.flush()`（行 327），为不可达死代码（疑为编辑残留）；物理删除分支内的 `await session.flush()`（行 325）才是有效调用。死代码不影响运行结果，但误导后续维护者对该函数提交语义的理解。

## 预期行为
- none

## 定位锚点
- 文件: services/api/app/services/auth_service.py
- 符号: purge_deleted_accounts
- 锚点代码: `    return user_ids\n    await session.flush()`
- 行号参考: 326-327

## 修复指令
在 `services/api/app/services/auth_service.py` 的 `purge_deleted_accounts` 中，将锚点 `    return user_ids\n    await session.flush()` 替换为 `    return user_ids`。不得改动该函数其他语句。
